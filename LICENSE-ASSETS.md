# Exercise asset licensing

The exercise illustrations in `public/exercises/` are derived from the
Crosspoint exercise library with the project owner's permission for this
competition build.

Before the repository is published for the WebMCP Challenge, Crosspoint must
confirm the final public reuse license for these illustrations. If public
relicensing is not approved, replace them with original skeleton-style SVG
illustrations before submission.

No third-party trademarks may be embedded in the competition assets.
